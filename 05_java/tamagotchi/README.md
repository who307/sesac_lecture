# 다마고치 게임 기획서

수치와 규칙은 모두 `Pet`, `GameManager`, `Main`과 각 펫 클래스에 실제로 적힌 값입니다.

## 1. 게임 개요

펫을 골라 10일 동안 돌보고, 돌본 방식에 따라 진화 형태와 최종 등급이 달라지는 턴제 육성 게임입니다.

| 항목 | 내용 | 코드 위치 |
| --- | --- | --- |
| 장르 | 턴제 육성 시뮬레이션 (콘솔) |  |
| 플레이 기간 | 10일, 하루 행동 4회 = 총 40턴 | `GameManager.maxDays`, `maxAction` |
| 시작 | 이름 입력 후 펫 선택: 1. 강아지 2. 드래곤 3. 알 | `Main` |
| 목표 | 게임 오버 없이 10일을 채워 높은 등급 얻기 | `GameManager.showEnding()` |
| 핵심 재미 | 같은 행동도 펫마다 효과가 다르고, 알과 드래곤은 돌본 방식에 따라 태어날 종류와 진화 방향이 바뀜 |  |

## 2. 펫 상태 수치

모든 펫이 같은 다섯 수치를 가지며, 행동 뒤 `checkStatus()`가 0~100 범위로 고정합니다. 나이 수치는 따로 없고 `GameManager.day`가 그 역할을 합니다.

| 수치 | 코드 필드 | 시작값 | 의미 | 경고 구간 | 게임 오버 |
| --- | --- | --- | --- | --- | --- |
| 배고픔 | `hunger` | 0 | 높을수록 배고픔 | 80 이상 | 100 |
| 행복도 | `happiness` | 80 | 높을수록 기분 좋음 | 20 이하 | 0 |
| 체력 | `hp` | 100 | 0이 되면 쓰러짐 | 20 이하 | 0 |
| 청결도 | `cleanliness` | 100 | 낮을수록 더러움 | 20 이하 | 없음 |
| 친밀도 | `affection` | 0 | 점수에 더해짐, 행동에 따라 줄어들 수 있음 | 없음 | 없음 |

경고는 매 행동 뒤 `checkWarning()`이 검사해, 해당하는 수치마다 한 줄씩 출력합니다.

## 3. 공통 행동

메뉴 1~5는 모든 펫이 같고, 6번 특수행동은 펫마다 다릅니다(4장). 아래는 `Pet` 기본값이고, 펫 종류가 일부 행동을 덮어씁니다. 0번을 고르면 게임이 즉시 끝납니다.

| 행동 | 배고픔 | 행복도 | 체력 | 청결도 | 친밀도 | 조건 |
| --- | --- | --- | --- | --- | --- | --- |
| 1. 밥 주기 | -25 | +10 | +5 | 0 | 0 | 배고픔 10 이하면 거부(친밀도 -5). 30 이하면 과식: 배고픔 -10, 행복도 -10, 체력 -10, 친밀도 -5 |
| 2. 산책하기 | +15 | +15 | -15 | -10 | +5 | 체력 20 이하면 거부 |
| 3. 놀아주기 | +10 | +20 | -5 | -5 | +10 | 체력 20 이하면 거부 |
| 4. 씻기기 | 0 | +5 | 0 | +20 | 0 |  |
| 5. 재우기 | +15 | +15 | +20 | 0 | 0 |  |
| 시간 경과 (매 행동 뒤 자동) | +5 | -3 | 0 | -5 | 0 | `passTime()`, 거부된 행동 뒤에도 적용 |

거부된 행동도 하루 행동 4회 중 1회로 셈니다. 알 상태에서는 이 표가 적용되지 않고 수치가 전혀 변하지 않습니다(4장 알 부화 규칙).

## 4. 펫 종류와 진화

구현된 펫은 알, 강아지 계열 3종, 드래곤 계열 4종입니다. 알은 2일차 아침에 1일차의 돌봄에 따라 강아지나 드래곤으로 부화합니다. 강아지는 정해진 날(3·7일차)에 항상 같은 모습으로, 드래곤은 5일차에 수치에 따라 세 갈래로 진화합니다. 진화해도 이름과 현재 수치는 그대로 이어지고, 앞 형태의 특징도 상속으로 남습니다.

- 🥚 알 (1일차, 행동 횟수만 기록)
    - 산책 최다 → 🐶 강아지 (2일차 부화)
        - 3일차 → 날개 강아지
            - 7일차 → ⭐ 하늘의 마법사
    - 그 외 → 🐉 드래곤 (2일차 부화)
        - 5일차, 행복도 최고 → ⭐ 불꽃 드래곤
        - 5일차, 청결도 최고 → ⭐ 얼음 드래곤
        - 5일차, 체력 최고 → ⭐ 강철 드래곤
    - 밥만 줌 → ❌ 부화 실패 (엔딩)

⭐ 최종 형태 · ❌ 엔딩 · 강아지·드래곤을 처음부터 고르면 알 없이 1일차부터 키웁니다.

진화 방향이 곧 상속 방향입니다. 예를 들어 `SkyDog`은 `FlyDog`을, `FlyDog`은 `Dog`을 상속합니다.

| 종류 | 클래스 | 등장 | 특징 | 6. 특수행동 | 진화 보너스 |
| --- | --- | --- | --- | --- | --- |
| 강아지 | `Dog` | 1일차 | 산책 시 행복도 +10 추가. 시간 경과 시 행복도 2 더 감소 | 꼬리 흔들기 (효과 없음) | 10 |
| 날개 강아지 | `FlyDog` | 3일차 | 강아지 특징 유지 | 하늘 날기: 행복도 +10 | 20 |
| 하늘의 마법사 | `SkyDog` | 7일차 | 날개 강아지 특징 유지 | 구름 휴식: 행복도 +10, 체력 +10 | 35 |
| 드래곤 | `Dragon` | 1일차 | 놀아주기 시 행복도 +10 추가. 시간 경과 시 행복도 5 더 감소 | 불 뿜기 (효과 없음) | 20 |
| 불꽃 드래곤 | `FireDragon` | 5일차 | 드래곤 특징 유지 | 화염 브레스: 행복도 +15 | 40 |
| 얼음 드래곤 | `IceDragon` | 5일차 | 씻기기 시 행복도 +10 추가 | 눈꽃 피우기 (효과 없음) | 40 |
| 강철 드래곤 | `SteelDragon` | 5일차 | 시간 경과 시 행복도 +5로 드래곤 페널티 상쇄 | 바위 부수기 (효과 없음) | 40 |

드래곤 진화 조건은 5일차 아침의 행복도·청결도·체력 중 가장 높은 값입니다. 값이 같으면 행복도 → 청결도 → 체력 순으로 우선합니다.

### 알 부화 규칙 (`Egg`)

알은 어떤 행동에도 수치가 변하지 않고, 행동 횟수만 기록합니다. 시간이 흘러도 수치가 그대로여서 알 상태에서는 게임 오버가 없습니다.

| 행동 | 알의 반응 | 횟수 기록 |
| --- | --- | --- |
| 1. 밥 주기 | "알은 아직 밥을 먹을 수 없어요!" (행동 1회는 소모) | 안 함 |
| 2~5. 산책·놀아주기·씻기기·재우기 | 살짝 흔들림 | 함 |
| 6. 특수행동 | 따뜻하게 품어주기 | 안 함 |

2일차 아침 부화 결과는 기록된 횟수로 정해집니다.

| 조건 | 결과 |
| --- | --- |
| 산책이 놀아주기·씻기기·재우기보다 많음 | 강아지로 부화 |
| 기록된 행동이 하나도 없음 (밥과 품어주기만 함) | 부화 실패 엔딩 (6장) |
| 그 외 (놀이 위주 등) | 드래곤으로 부화 |

부화일을 3일차가 아닌 2일차로 한 이유는, 3일차에 부화하면 같은 날 아침의 강아지 진화와 겹쳐 강아지가 진화하지 못하기 때문입니다. 부화한 펫은 알의 수치(시작값)를 그대로 이어받습니다.

## 5. 게임 진행 규칙

하루는 아침 진화 검사 → 상태 표시 → 행동 4회 순서로 흘러갑니다(`GameManager.startGame()`).

1. "N일차" 머리글을 출력합니다.
2. `pet.evolve(day)`를 호출합니다. 다른 객체가 돌아오면 교체하고 진화 이미지와 소리를 출력합니다. 알이 부화에 실패했으면 여기서 게임이 끝납니다.
3. `getInfo()`로 펫 상태를 보여줍니다.
4. 행동을 4번 고릅니다. 매번 행동 → 시간 경과 → 경고 검사 → 게임 오버 검사 순서입니다.
5. 10일차가 끝나면 엔딩, 아니면 다음 날로 넘어갑니다.

### 진화 방식

- 진화 시점은 `GameManager`가 아니라 각 펫이 정합니다. 펫 클래스가 `evolve(int day)`를 오버라이딩해 조건이 맞으면 새 객체를, 아니면 `this`를 돌려줍니다.
- 새 객체는 복사 생성자 `Pet(Pet prev)`로 만들어 이름과 수치를 그대로 이어받습니다.
- 최종 형태는 `evolve(int day)`에서 항상 `this`를 돌려주어 더 진화하지 않습니다.
- 새 펫을 추가할 때도 이 방식을 따르면 `GameManager`를 고칠 필요가 없습니다. 알의 부화도 같은 방식이고, 부화 실패만 GameManager가 따로 확인합니다.

### 특수행동 (메뉴 6번)

모든 펫의 메뉴에 항상 보이며, 효과는 펫마다 다릅니다(4장 표). 횟수 제한이나 거부 조건은 없습니다.

## 6. 게임 결과

10일을 채우면 점수로 S~C 등급을 매기고, 그 전에 수치가 한계에 닿으면 게임 오버입니다.

### 게임 오버 (`checkGameOver()`, 매 행동 뒤)

| 조건 | 메시지 |
| --- | --- |
| 체력 0 | (이름)이(가) 지쳐 쓰러졌습니다. |
| 배고픔 100 | (이름)이(가) 굶주림으로 생존에 실패했습니다. |
| 행복도 0 | (이름)이(가) 집을 나갔습니다. |

알 상태에서는 위 조건에 걸리지 않는 대신, 1일차에 밥과 품어주기만 하면 2일차 아침 **깨어나지 못한 알** 엔딩으로 끝납니다. 이때는 점수와 등급을 매기지 않습니다.

```
===== 엔딩: 깨어나지 못한 알 =====
(이름)은(는) 끝내 알에서 깨어나지 못했어요...
알에게는 밥보다 따뜻한 손길이 필요했나 봐요.
게임을 종료합니다.
```

### 엔딩 (`showEnding()`)

**점수 = 친밀도 + 진화 보너스 + (행복도 + 체력 + 청결도 + (100 − 배고픔)) ÷ 4**

진화 보너스는 마지막 형태의 값입니다(4장 표, `getEvolutionBonus()`). 나눗셈은 정수 나눗셈이라 소수점은 버려집니다.

| 등급 | 점수 | 메시지 |
| --- | --- | --- |
| S | 180 이상 | 야생의 우두머리가 되었어요! |
| A | 140~179 | 야생에 잘 적응했어요! |
| B | 100~139 | 시간이 걸렸지만 야생에 적응했어요! |
| C | 100 미만 | 야생 적응에 실패해 보호소로 돌아왔어요. |

최대 점수는 친밀도 100 + 상태 100 + 보너스 40 = 240점입니다. 방생 장소와 작별 인사는 아직 펫마다 나뉘지 않았습니다.

## 7. 클래스 구조

펫은 추상 클래스 `Pet`을 상속하고, 진화 형태는 진화 전 클래스를 다시 상속합니다. 그래서 상속 구조가 곧 진화 트리입니다(4장).

### 파일 구조

```
tamagotchi/
├── README.md
├── tamagotchi.iml
└── src/
    ├── Main/
    │   └── Main.java              # 진입점: 이름·펫 선택 후 게임 시작
    ├── game/
    │   └── GameManager.java       # 하루 진행, 메뉴, 진화 호출, 엔딩
    └── pet/
        ├── Pet.java               # 추상 부모 클래스: 공통 수치·행동
        ├── egg/
        │   └── Egg.java           # 알 (2일차 부화)
        ├── dog/
        │   ├── Dog.java           # 강아지
        │   ├── FlyDog.java        # 날개 강아지 (extends Dog)
        │   └── SkyDog.java        # 하늘의 마법사 (extends FlyDog)
        └── dragon/
            ├── Dragon.java        # 드래곤
            ├── FireDragon.java    # 불꽃 드래곤 (extends Dragon)
            ├── IceDragon.java     # 얼음 드래곤 (extends Dragon)
            └── SteelDragon.java   # 강철 드래곤 (extends Dragon)
```

### 상속 구조

```
                    Pet (abstract)
        ┌────────────┼──────────────┐
       Egg          Dog           Dragon
                     │       ┌──────┼───────┐
                   FlyDog  Fire    Ice    Steel
                     │     Dragon  Dragon  Dragon
                   SkyDog
```

### 패키지별 역할

| 패키지 | 클래스 | 역할 |
| --- | --- | --- |
| `Main` | `Main` | 이름·펫 종류 입력, `GameManager` 시작 |
| `game` | `GameManager` | 하루 흐름, 메뉴, 진화 호출, 경고·게임 오버·엔딩, 알 부화 실패 확인 |
| `pet` | `Pet` (추상) | 공통 수치와 행동, 복사 생성자, 기본 `evolve(int day)` |
| `pet.egg` | `Egg` | 알: 행동 횟수 기록, 2일차 부화 또는 부화 실패 |
| `pet.dog` | `Dog`, `FlyDog`, `SkyDog` | 강아지 계열 |
| `pet.dragon` | `Dragon`, `FireDragon`, `IceDragon`, `SteelDragon` | 드래곤 계열 |

각 펫이 구현해야 하는 추상 메서드는 `makeSound()`, `specialAction()`, `showHappyImage()`, `showUnhappyImage()`입니다.
