### 반응형 CSS 처리 방식 비교

| **구분** | **미디어 쿼리 (@media)** | **컨테이너 쿼리 (@container)** |
| --- | --- | --- |
| **기준** | 브라우저 창(Viewport)의 너비/높이 | 부모(상위) 요소의 너비/높이 |
| **주요 용도** | 전체 페이지 레이아웃 (데스크톱/모바일) | 독립적이고 재사용 가능한 컴포넌트 스타일링 |
| **특징** | 사이드바 유무 등 부모 크기 변화를 인지 못 함 | 부모 영역 폭이 좁아지면 알아서 형태 변경 |

### CSS 반응형 쿼리 (`@media` & `@container`)

```css
/* 1. 미디어 쿼리: 브라우저 화면 너비(Viewport) 기준으로 작동 */
@media (max-width: 768px) {
  .card {
    background-color: lightblue;
  }
}

/* 반응형 구간 설정 예시 */
/* TABLET */
@media (768px <= width <= 1219px) {
}

/* MOBILE */
@media (width <= 767px) {
}
@media (width <= 479px) {
}

/* 2. 컨테이너 쿼리: 부모 요소(.card-wrapper)의 크기를 기준으로 작동 */
.card-wrapper {
  /* 부모 요소를 컨테이너 기준점으로 지정 (필수) */
  container-type: inline-size;
  container-name: card-container;
}

/* 부모 컨테이너 너비가 400px 이하일 때 작동 */
@container card-container (max-width: 400px) {
  .card {
    background-color: lightcoral;
  }
}

```

### JavaScript 미디어 쿼리 (`window.matchMedia`)

```javascript
/**
 * window.matchMedia()
 * 브라우저 창 크기를 감지하여 조건 변경 시 이벤트를 발생시킨다.
 */

// 1. 미디어 쿼리 조건 설정
const mediaQuery = window.matchMedia('(max-width: 768px)');

// 2. 상태 변경 시 실행할 콜백 함수
function handleScreenChange(e) {
  if (e.matches) {
    console.log('화면 너비 768px 이하');
    document.body.classList.add('is-mobile');
  } else {
    console.log('화면 너비 768px 초과');
    document.body.classList.remove('is-mobile');
  }
}

// 3. 초기 상태 1회 실행 및 감지 리스너 등록
handleScreenChange(mediaQuery);
mediaQuery.addEventListener('change', handleScreenChange);

```

### JavaScript 컨테이너 쿼리 (`ResizeObserver`)

```html
<!-- HTML 구조 -->
<div id="parent-container" style="width: 50%;">
  <div id="child-card">카드 콘텐츠</div>
</div>

```

```javascript
/**
 * ResizeObserver API
 * 특정 부모 요소의 크기 변화를 실시간으로 관찰하여 컴포넌트 단위 조작을 수행한다.
 */

const parentContainer = document.getElementById('parent-container');
const childCard = document.getElementById('child-card');

// 1. ResizeObserver 생성 (크기 변화 감지 시 실행)
const observer = new ResizeObserver((entries) => {
  for (let entry of entries) {
    // entry.contentRect에서 부모 요소의 실제 너비 추출
    const parentWidth = entry.contentRect.width;

    if (parentWidth <= 400) {
      childCard.classList.add('small-layout');
      childCard.classList.remove('large-layout');
    } else {
      childCard.classList.add('large-layout');
      childCard.classList.remove('small-layout');
    }
  }
});

// 2. 관찰할 부모 요소 지정
observer.observe(parentContainer);
